현재 프로젝트 폴더의 `AGENTS.md`, `PROJECT.md`, `CHECKLIST.md`를 먼저 처음부터 끝까지 읽어줘.

이 프로젝트는 **Eco Express**라는 청년 ESG 공조기술 아카데미 참가자를 위한 '미션 트래킹 및 리워드(굿즈) 웹앱'이야.

`PROJECT.md`에 작성된 서비스 요구사항과 개발 순서를 기준으로 구현하고, `CHECKLIST.md`를 개발 진행상황 관리에 사용해줘.
한 번에 모든 기능을 임의로 축약해서 만들지 말고 반드시 단계별로 구현해줘.

개발 순서는 다음 원칙을 따라줘.
1. 먼저 기본 웹앱 UI와 화면 구조(KTX, 풀밭 등 팝업 부스 테마 반영)를 만든다. (PC와 모바일 모두 호환되는 반응형)
2. 아카데미 미션 기능(미션 1: 냉동사이클 조립 교육 영상 시각화, 미션 2: 초고속 냉방 제어 실험 영상 시각화)을 구현한다.
3. 팝업 부스 미션(미션 3: 기후 위기에서 동물들을 구하라, 미션 4: 나비효과로부터 지구를 지켜라) 로직을 구현하여 올바른 선택(예: 에어컨 적정온도 유지 등) 시 추가 점수를 주도록 한다.
4. 미션 1, 2에서는 KTX 초고속 환경 기반의 가상 공조 시뮬레이션 데이터를 영상 및 시각적 차트로 보여준다.
5. 미션 성공 시 ECO POINT를 지급하는 기능을 구현한다.
6. ECO WALLET(포인트 지갑)과 포인트 획득/사용 내역을 구현한다.
7. 리워드 숍(굿즈 교환소) 화면과 포인트로 굿즈를 교환하는 기능을 구현한다.
8. Supabase를 연결해 청년 참가자들의 회원가입/로그인/로그아웃/회원탈퇴와 실제 데이터 저장 기능을 구현한다.
9. 가입 인증 메일 등의 발송 제한에 걸리지 않도록 Supabase Auth에 Custom SMTP(예: Resend, SendGrid 등) 설정을 반영한다.
10. 기존 localStorage 또는 임시 데이터가 있다면 Supabase 데이터 구조로 전환한다.
11. 사용자별 미션 진행도, 획득 포인트, 굿즈 교환 내역이 분리되도록 구현한다.
12. Supabase RLS 정책을 적용해 사용자가 자신의 데이터만 접근할 수 있도록 한다.
13. 마지막 단계에서 Render에 배포할 수 있는 구조로 프로젝트를 정리한다.
14. 필요한 환경변수를 `.env.example`에 정리하고 비밀키는 소스코드에 직접 작성하지 않는다.

각 단계가 완료될 때마다:
* 해당 기능이 실제로 동작하는지 확인하고
* 기존 기능이 깨지지 않았는지 확인하고
* 완료된 항목을 `CHECKLIST.md`에서 체크하고
* 문제가 있다면 다음 단계로 넘어가기 전에 수정해줘.

디자인은 `PROJECT.md`에 정의된 디자인 시스템을 반드시 따라줘.
기본 디자인:
* White + Blue 기반에 KTX, 풀밭 등의 에코 익스프레스 테마 색상(자연 친화적 Green 요소) 가미
* 청년(대학생, 직장인) 타깃의 모던하고 깔끔한 UI (금융/쇼핑 앱 스타일 참고)
* 둥근 카드와 버튼, PC/모바일 모두 대응 가능한 모바일 우선 반응형 디자인
* 정상/성공 상태는 Blue 또는 Green
* 위험, 온실효과 심화, 잘못된 선택(빙하가 녹는 상황 등)은 Red

데이터베이스는 Supabase를 사용하고 최소한 다음 데이터를 관리할 수 있게 설계해줘.
* 사용자 (청년 참가자)
* 아카데미 미션 4종 (교육, 실험, 동물 구하기, 나비효과) 목록 및 사용자별 달성 기록
* ECO POINT 적립/사용 기록
* 리워드 굿즈 상품 및 교환 내역
* 사용자 ECO LEVEL (ESG 실천 레벨)

최종적으로 사용자가 다음 흐름을 실제로 경험할 수 있어야 한다.
참가자 회원가입 및 로그인 → 홈 화면(나의 미션 진행도 확인) → 미션 1, 2 시청(공조 교육 및 실험 데이터 영상 시각화 확인) → 팝업 부스 참여(미션 3, 4 선택지에 따른 결과 확인) → 미션 성공 및 추가 ECO POINT 획득 → 포인트 지갑 확인 → 굿즈 숍에서 리워드 교환 → 환경 보호 실천 리포트 확인 → 로그아웃/회원탈퇴.

마지막으로 Render에 배포하여 실제 팝업 현장에서 청년들이 모바일과 PC로 접속 가능한 웹서비스가 될 수 있도록 프로젝트를 구성해줘.
먼저 파일을 수정하기 전에 `AGENTS.md`, `PROJECT.md`, `CHECKLIST.md`를 분석하고, 현재 구현해야 할 개발 단계를 짧게 정리한 뒤 1단계부터 시작해줘.
